# MedApp Icons

This directory should contain PWA icons in the following sizes:

- icon-72x72.png
- icon-96x96.png
- icon-128x128.png
- icon-144x144.png
- icon-152x152.png
- icon-192x192.png
- icon-384x384.png
- icon-512x512.png

For now, you can use placeholder icons or create simple ones using any image editor.
The icons should have a medical/pharmacy theme (like a pill, cross, or medicine bottle).

You can generate these icons using online PWA icon generators or create them manually.
